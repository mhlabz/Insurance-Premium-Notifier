# Application screenshots

Place genuine screenshots captured from the running Insurance Premium Notifier app in this folder.

Recommended filenames:
- dashboard.png
- add-policy.png
- all-policies.png
- reminders.png
- lapsed-policies.png

To capture on Windows, open the page in your browser and press Win + Shift + S. Save the image in this folder using the matching filename.

Before committing screenshots, use sample policy information only. Do not expose real names, email addresses, phone numbers, policy numbers, or other personal information.

## Short demo GIF

A demo GIF can be added here as demo.gif. Record a short walkthrough of the local application (dashboard → add a sample policy → run Monitor Now → view reminders). Keep the recording free of personal data. Tools such as ScreenToGif can capture and export the walkthrough as a GIF.
